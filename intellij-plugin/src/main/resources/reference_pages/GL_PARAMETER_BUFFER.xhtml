OpenGL 4.6 token

GL_PARAMETER_BUFFER

Target for the buffer containing indirect draw counts. The drawcount argument of a count-based multi-draw points to a byte offset in this buffer.

glBindBuffer(GL_PARAMETER_BUFFER, countBuffer);

glMultiDrawArraysIndirectCount

GLSL Support supplement based on the Khronos OpenGL 4.6 core specification
