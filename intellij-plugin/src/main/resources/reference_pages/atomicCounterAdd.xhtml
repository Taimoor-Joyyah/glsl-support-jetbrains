atomicCounterAdd

GLSL 4.60 atomic counter function

uint atomicCounterAdd(atomic_uint counter, uint data);

Atomically adds data and returns the previous 32-bit unsigned counter value.

layout(binding = 0, offset = 0) uniform atomic_uint counter;
// Inside a shader function
uint previous = atomicCounterAdd(counter, 1u);

The counter is stored in an OpenGL atomic counter buffer.
