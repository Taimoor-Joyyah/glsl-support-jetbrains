OpenGL 4.6 token

GL_MAX_TEXTURE_MAX_ANISOTROPY

Query the implementation limit for anisotropic filtering and use it to bound the texture or sampler setting.

GLfloat maximum;
glGetFloatv(GL_MAX_TEXTURE_MAX_ANISOTROPY, &maximum);
