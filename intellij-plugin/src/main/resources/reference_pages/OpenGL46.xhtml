OpenGL 4.6 and GLSL 4.60

The Khronos reference includes glMultiDrawArraysIndirectCount, glMultiDrawElementsIndirectCount, and glPolygonOffsetClamp. GLSL Support supplies entries for the other additions from the OpenGL 4.6 core specification and the GLSL 4.60 specification. Both specifications open offline.
