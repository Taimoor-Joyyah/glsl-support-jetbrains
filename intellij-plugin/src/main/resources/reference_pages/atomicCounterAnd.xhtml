atomicCounterAnd

GLSL 4.60 atomic counter function

uint atomicCounterAnd(atomic_uint counter, uint data);

Atomically applies bitwise AND with data and returns the previous 32-bit unsigned counter value.

layout(binding = 0, offset = 0) uniform atomic_uint counter;
// Inside a shader function
uint previous = atomicCounterAnd(counter, 1u);

The counter is stored in an OpenGL atomic counter buffer.
