OpenGL 4.6 query target

GL_CLIPPING_OUTPUT_PRIMITIVES

Select this pipeline statistics target to count primitives leaving clipping over a query interval. Read the query object after the interval ends.

glBeginQuery(GL_CLIPPING_OUTPUT_PRIMITIVES, query);
// Issue workload.
glEndQuery(GL_CLIPPING_OUTPUT_PRIMITIVES);
GLuint64 count;
glGetQueryObjectui64v(query, GL_QUERY_RESULT, &count);
