GL_TEXTURE_MAX_ANISOTROPY

OpenGL 4.6 token

GL_TEXTURE_MAX_ANISOTROPY

Texture or sampler parameter controlling the requested degree of anisotropic filtering. One selects the default isotropic behavior.

glSamplerParameterf(sampler, GL_TEXTURE_MAX_ANISOTROPY, 2.0f);
