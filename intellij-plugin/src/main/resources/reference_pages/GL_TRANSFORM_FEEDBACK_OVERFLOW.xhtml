OpenGL 4.6 token

GL_TRANSFORM_FEEDBACK_OVERFLOW

Boolean query target that detects whether any stream overflowed its transform feedback storage during the query interval.

glBeginQuery(GL_TRANSFORM_FEEDBACK_OVERFLOW, query);
// Draw with transform feedback active.
glEndQuery(GL_TRANSFORM_FEEDBACK_OVERFLOW);
