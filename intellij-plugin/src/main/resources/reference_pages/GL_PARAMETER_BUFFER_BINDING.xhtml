GL_PARAMETER_BUFFER_BINDING

OpenGL 4.6 token

GL_PARAMETER_BUFFER_BINDING

Query the name of the buffer bound to GL_PARAMETER_BUFFER. The initial binding is zero.

GLint buffer;
glGetIntegerv(GL_PARAMETER_BUFFER_BINDING, &buffer);
