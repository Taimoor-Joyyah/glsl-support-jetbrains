GL_NUM_SPIR_V_EXTENSIONS

OpenGL 4.6 token

GL_NUM_SPIR_V_EXTENSIONS

Query the number of SPIR-V extension strings, then enumerate indices from zero up to that count.

GLint count;
glGetIntegerv(GL_NUM_SPIR_V_EXTENSIONS, &count);
