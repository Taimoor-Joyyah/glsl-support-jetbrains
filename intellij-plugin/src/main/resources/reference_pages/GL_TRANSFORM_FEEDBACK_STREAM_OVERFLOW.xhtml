OpenGL 4.6 token

GL_TRANSFORM_FEEDBACK_STREAM_OVERFLOW

Boolean indexed query target for overflow on a selected transform feedback stream.

glBeginQueryIndexed(GL_TRANSFORM_FEEDBACK_STREAM_OVERFLOW, stream, query);
// Draw with transform feedback active.
glEndQueryIndexed(GL_TRANSFORM_FEEDBACK_STREAM_OVERFLOW, stream);
