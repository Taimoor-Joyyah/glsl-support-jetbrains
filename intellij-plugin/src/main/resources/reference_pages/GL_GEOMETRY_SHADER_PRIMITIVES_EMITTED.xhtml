GL_GEOMETRY_SHADER_PRIMITIVES_EMITTED

OpenGL 4.6 query target

GL_GEOMETRY_SHADER_PRIMITIVES_EMITTED

Select this pipeline statistics target to count primitives emitted by geometry shaders over a query interval. Read the query object after the interval ends.

glBeginQuery(GL_GEOMETRY_SHADER_PRIMITIVES_EMITTED, query);
// Issue workload.
glEndQuery(GL_GEOMETRY_SHADER_PRIMITIVES_EMITTED);
GLuint64 count;
glGetQueryObjectui64v(query, GL_QUERY_RESULT, &count);
