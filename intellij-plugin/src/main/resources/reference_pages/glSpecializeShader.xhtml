glSpecializeShader

OpenGL 4.6 command

void glSpecializeShader(GLuint shader, const GLchar *entryPoint, GLuint count, const GLuint *ids, const GLuint *values);

Select the entry point of a SPIR-V shader loaded with glShaderBinary. Supply specialization IDs and their 32-bit value representations before linking the program. IDs omitted from the call retain their module defaults.

GLuint id = 4, count = 8;
glSpecializeShader(shader, "main", 1, &id, &count);

Check GL_COMPILE_STATUS and the shader info log after specialization. To specialize another entry point or another set of constants, load the module again.

GL_SHADER_BINARY_FORMAT_SPIR_V · GL_SPIR_V_BINARY · constant_id
