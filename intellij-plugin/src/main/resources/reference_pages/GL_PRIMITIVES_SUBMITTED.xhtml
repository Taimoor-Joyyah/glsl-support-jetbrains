OpenGL 4.6 query target

GL_PRIMITIVES_SUBMITTED

Select this pipeline statistics target to count primitives submitted by drawing commands over a query interval. Read the query object after the interval ends.

glBeginQuery(GL_PRIMITIVES_SUBMITTED, query);
// Issue workload.
glEndQuery(GL_PRIMITIVES_SUBMITTED);
GLuint64 count;
glGetQueryObjectui64v(query, GL_QUERY_RESULT, &count);
